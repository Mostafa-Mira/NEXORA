# NEXORA Landing Page

واجهة متجر إلكترونيات عربية RTL مستقلة، مصممة كعرض Portfolio باستخدام HTML وCSS وJavaScript فقط.

## التشغيل محليًا

لا تحتاج إلى تثبيت أي حزم. افتح `index.html` مباشرة في متصفح حديث، أو شغّل خادمًا ثابتًا من داخل مجلد المشروع:

```powershell
cd NEXORA-Landing-Page
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

- `index.html`: البنية والمحتوى العربي وبيانات SEO.
- `css/style.css`: التصميم المتجاوب، RTL، حالات التفاعل وإتاحة الاستخدام.
- `js/main.js`: المنتجات التجريبية، الفلترة، السلة، localStorage، الأسئلة الشائعة والـ modal.
- `assets/images/`: رسوم SVG أصلية خفيفة لعرض المنتجات؛ لا تحتاج إلى تراخيص خارجية.

## التخصيص

1. عدّل قائمة `products` في `js/main.js` لتغيير المنتجات والأسعار والصور.
2. استبدل بيانات الاتصال وروابط الشبكات الاجتماعية التجريبية في `index.html` بالبيانات الحقيقية قبل النشر.
3. حدّث النصوص والسياسات التجريبية، ثم اربط Backend وبوابة دفع وشحن للطلبات الفعلية.
4. يمكن استبدال رسوم SVG بصور WebP أصلية مع الإبقاء على أبعاد ثابتة لتجنب تغيّر التخطيط.

## النشر

المشروع static وجاهز للنشر على Netlify أو Vercel أو GitHub Pages: ارفع محتويات مجلد `NEXORA-Landing-Page` كما هي، واجعل `index.html` ملف البداية. لا توجد أي مفاتيح أو إعدادات خادم مطلوبة.

> جميع المنتجات والأسعار والعروض والمراجعات والسياسات المعروضة هي بيانات تجريبية، ولا يتم تنفيذ دفع أو طلبات حقيقية.
